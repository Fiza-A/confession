# Made With Love

A fully responsive romantic digital love letter website built with React, Tailwind CSS, and Framer Motion.

## Setup

```bash
npm install
npm run dev
```

## Personalize

Edit `src/data/loveConfig.js` to change:

- `loverName`
- `myName`
- `loveLetterText`
- `memoryImages`
- `memoryCaptions`
- `reasonsILoveYou`
- `timelineEvents`
- `secretMessage`
- `finalMessage`

The unlock code is also in that file as `secretCode`. The default is `143`.
